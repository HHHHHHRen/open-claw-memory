## RO 隔网 LBM 模拟 - CF 结构（菱形编织网 + 柱状节点）

### 几何参数（论文 SI Figure S1）
- 纤维直径 d = **0.4 mm**
- 柱状节点直径 D = **0.566 mm**（论文明确值，非估算）
- 隔网厚度 h = **0.787 mm**（31 mil）
- 纤维法向间距 pitch = **2.6 mm**（文献 filament spacing 的定义）
- 编织角 α = 90°

### 关键几何推导
- 法向间距是"不变量"，改变编织角时 pitch 不变，节点距和边长变
- 对于 90°：水平节点距 L_h = pitch / sin(45°) = **3.677 mm**
- 垂直节点距 L_v = pitch / cos(45°) = **3.677 mm**
- 沿纤维边长 L_seg = pitch / sin(90°) = **2.6 mm**

### MATLAB 代码修正
1. **节点从球形改圆柱形**：Z 向贯穿全高（h_spacer），XY 平面内圆盘判定
2. **布尔并集优化**：`solid = fiber_mask | node_mask`，节点区不重复标记纤维
3. **相位偏移**：`phase_shift = 0.5` 使节点对齐到计算域边界（论文左图效果），纤维和节点循环都要加

### 当前模拟问题
- 网格：368 × 221 × 16 = 1.3M 格点
- 孔隙率：**84.0%**（偏高，标准隔网 65-75%）
- τ = 0.505, Fx = 1.0e-4
- **密度波动过大**：ρ = [0.936, 1.128]，波动 ±9.4%，远超弱压缩假设（±1%）
- 最大马赫数 ~0.47，接近超音速

### 待执行修复

### 可视化错位问题
- C 代码存数据是 C-order (nx,ny,nz)，MATLAB 切片默认 (z,y,x)
- 切片方式：`ux(:, :, kz)'` 或 `permute(ux, [3,2,1])` 后 `ux(kz, :, :)`
- 验证法：几何骨架（solid_k）叠加速度场，看白色轮廓是否和低速区重合
