# 2026-03-12 记忆

## 出行规划

**特斯拉自驾行程：承德县 → 北京八达岭奥特莱斯**
- 起点：承德县盛世名邸
- 终点：北京八达岭奥特莱斯（昌平区南口镇）
- 距离：约200公里单程，往返约400公里
- 耗时：单程2.5-3小时

**路线**：承德县 → 长深高速/大广高速 → 京承高速 → 北六环 → 京藏高速(G6) → 南口出口 → 八达岭奥特莱斯

**费用估算（往返）**：
- 高速费：160-200元
- 电费：
  - 家充为主：约36元（15度/100km × 0.6元/度 × 400km）
  - 第三方充电桩：约72元
  - 特斯拉超充：约120元
- 总成本：约200-320元（取决于充电方式）

**用户情况**：
- 车辆：特斯拉电车，北京牌照
- 驾驶水平：新手（"开车很菜"）
- 充电偏好：建议出发前电量不低于80%

**实用信息**：
- 八达岭奥特莱斯有免费停车场
- 奥特莱斯内有特斯拉超充桩
- 京藏高速昌平段货车较多，需注意安全
- 返程进京方向周末可能拥堵
